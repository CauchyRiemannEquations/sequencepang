# STAR TIME

설정은 `client/src/gameConstants.js`의 `STAR_*` 6개 값에서 조절합니다. 기본값은 등장률 0.08, 필요 별 5개, 지속 8초, 연장 1초, 남은 시간 상한 15초, 점수 배율 2입니다.

## 기존 규칙과의 관계

- 별은 일반 숫자의 `isStar` 속성입니다. 숫자 풀, 수열 판정, 드래그 히트테스트, 중력과 리필은 기존 방식을 사용합니다. 피버 작동 블록에는 별이 붙지 않습니다.
- 한 유효 수열에 별이 여러 개 있어도 보상은 한 번입니다. 크로스팡/풀보드팡의 부수 제거는 별을 지급하지 않습니다. 제거 대기 중 같은 별을 다시 입력해도 중복 지급하지 않습니다.
- 다섯 번째 별을 얻은 수열부터 점수 ×2가 적용됩니다. 기존 콤보·반복·피버·라스트팡 배율 및 반올림을 적용한 뒤 STAR 배율을 적용합니다. 팡의 추가 점수도 같은 방식입니다.
- STAR TIME 중 콤보 만료만 보류합니다. 성공 시 5초 충전, 잘못된 수열의 콤보 초기화/시간 페널티는 그대로입니다. 종료 후 보존한 콤보 시간부터 다시 줄어듭니다.
- STAR TIME은 `performance.now()` 기준 마감 시각을 사용합니다. 기존 100ms 게임 틱에서 표시를 갱신하고 수열 성공 직전에도 만료를 확인합니다. 별도 반복 타이머는 만들지 않습니다.
- STAR 발동/연장은 게임 제한시간을 바꾸지 않습니다. 기존 수열 성공 시간 보너스는 유지합니다. 기존 피버/팡 연출의 게임 시간 정지 역시 유지하며, STAR 시간은 그동안에도 흐릅니다. 제한시간 종료와 기존 드래그 유예 규칙을 그대로 따릅니다.
- 게임 종료/시작 시 별 상태와 HUD 알림 타이머를 초기화합니다. 최고점수 저장 및 제출 경로는 그대로 사용하며, 점수 버전은 1.4.0으로 올렸습니다.

## 등장률 근거

6×6 보드와 성공 시 선택 칸만 교체하는 기존 구조에서 8%는 초기 보드 평균 2.88개의 별입니다. 무작위 3~5칸 수열에 별이 포함될 확률은 약 22~34%로, 별을 찾아 선택하는 플레이를 유도하는 초기값입니다. 350ms의 일반 제거 연출과 5초 콤보 창을 고려해 작은 수열마다 보너스가 발동하지 않도록 잡았습니다. 실제 시작 화면의 별/일반 혼합 생성도 확인했습니다. 대규모 플레이 통계를 통한 최종 밸런스 보정은 별도입니다.

## 검증 (2026-09-22)

`npm test`와 `npm run build`를 실행합니다. 기존 판정/보드/팡 테스트 및 점수 패리티 벡터를 보존하고, STAR 상태/확률/점수 중첩/동일 값 리필/HUD 초기화 회귀 테스트를 추가했습니다.

로컬 브라우저에서 실제 게임을 시작해 혼합 생성을 확인했고, 무작위 보드에서 별을 찾아 연속 플레이하여 다섯 번째 별의 자연 발동도 확인했습니다. 경계 상황은 원본 엔진과 UI를 쓰는 임시 검증 화면에서 보드와 시계만 제어하여 재현했습니다. 해당 검증 화면은 배포하지 않습니다.
